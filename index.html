怎么弄一个 token
  1. 打开 github.com/settings/personal-access-tokens/new
  2. Repository access 选 Only select repositories，勾上 2012952877/520
  3. Permissions → Repository permissions → Contents 改成 Read and write
  4. 生成后把 github_pat_ 开头那串粘到上面

这个 token 只能动这一个仓库，过期了再发一个就行。
